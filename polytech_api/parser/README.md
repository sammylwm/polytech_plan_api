# Парсер расписания Московского Политеха

Пакет получает расписание с `https://rasp.dmami.ru` и преобразует его в модели Pydantic. Поддерживает обычное расписание, расписание сессии, выборку по датам и поиск лабораторных и практик.

Основной поток: `get_group()` получает JSON сайта, `parse_grid()` преобразует его в занятия, остальные функции выбирают даты и типы занятий.

## Функции для вызова из API

Сетевые функции асинхронные, поэтому вызываются через `await`. Их можно использовать внутри `async def` обработчика Django.

| Функция | Результат |
| --- | --- |
| `await get_schedule(group, session=False)` | Все занятия группы как недельная сетка или расписание сессии. Возвращает `list[Lesson]`. |
| `await get_schedule_period(group, start, end, session=False)` | Занятия на конкретные даты в диапазоне включительно. Возвращает `list[Lesson]`. |
| `await get_deadlines(group, start, end, session=False)` | Лабораторные и практики в диапазоне включительно. Возвращает `list[Deadline]`. |

`group` - номер группы строкой. `start` и `end` - объекты `datetime.date`. Для расписания сессии передай `session=True`. Для одного дня передай одинаковые `start` и `end`.

```python
from datetime import date

from parser import get_deadlines, get_schedule, get_schedule_period


async def load_schedule():
    lessons = await get_schedule("261-329")
    week = await get_schedule_period(
        "261-329",
        date(2026, 11, 16),
        date(2026, 11, 22),
    )
    deadlines = await get_deadlines(
        "261-329",
        date(2026, 11, 16),
        date(2026, 11, 22),
    )
    return lessons, week, deadlines
```

Лабораторные и практики здесь условно называются дедлайнами. Функции находят даты занятий, отдельные сроки сдачи они не получают.

## Получение и обработка данных

### `await get_group(group, session=False)`

Получает исходный JSON расписания через `httpx.AsyncClient`. Проверяет HTTP-статус и структуру ответа. Если сайт возвращает страницу с cookie `bpc`, устанавливает cookie и повторяет запрос. Всего допускается до трех попыток.

Возвращает словарь с исходными данными, без преобразования в модели занятий. После запроса HTTP-клиент закрывается. Кеширования нет.

### `parse_grid(data)`

Преобразует словарь из `get_group()` в `list[Lesson]`. Разбирает недельную сетку и сетку с конкретными датами сессии. Получает предмет, преподавателя, аудитории, тип занятия и даты. Время начала и окончания определяет по номеру пары из `PAIR_TIMES`.

Занятия без названия предмета пропускаются.

### `expand(lessons, start, end)`

Разворачивает недельную сетку в конкретные даты. Например, занятие по понедельникам превращается в занятия на каждый понедельник указанного периода.

Учитывает период проведения занятия `date_from` и `date_to`. Занятия с уже заданной датой включает, если дата входит в диапазон. Возвращает список, отсортированный по дате и номеру пары. Исходные модели не изменяет.

### `deadline_kind(lesson)`

Ищет ключевые слова в скобках названия предмета и в поле `type`. Возвращает:

- `"lab"` - лабораторная работа;
- `"practice"` - практика;
- `None` - подходящие ключевые слова не найдены.

Список ключевых слов задан в `DEADLINE_KEYWORDS`. Если найдены оба типа, приоритет имеет лабораторная работа.

### `find_deadlines(lessons, start, end)`

Вызывает `expand()` и оставляет лабораторные и практики. Возвращает `list[Deadline]`.

Поле `days_left` содержит количество дней от переданного `start` до даты занятия, а не от сегодняшнего дня.

### `clean_subject(subject)`

Удаляет все скобки с содержимым и лишние пробелы из названия. Например, `Физика (лабораторная работа)` превращается в `Физика`. Если после очистки строка пустая, возвращает исходное название.

## Внутренние функции

Эти функции используются внутри пакета, обычно вызывать их отдельно не требуется.

| Функция | Назначение |
| --- | --- |
| `_parse_date(value)` | Преобразует дату вида `2026-11-16` или `16.11.2026` в `datetime.date`. Для пустого значения возвращает `None`, для некорректного вызывает `ScheduleError`. |
| `_rooms(item)` | Получает названия аудиторий, очищает HTML и возвращает список непустых строк. |
| `Lesson.validate_dates()` | Автоматически проверяет наличие даты или дня недели и порядок границ периода проведения занятия. |
| `main()` в `schedule.py` | Тестовый запуск: получает расписание группы `261-329` и печатает занятия. |

## Модели результата

### `Lesson`

| Поле | Значение |
| --- | --- |
| `subject` | Название предмета. |
| `pair` | Номер пары от 1 до 7. |
| `start`, `end` | Время начала и окончания строками, например `09:00`. |
| `teacher` | Преподаватель. |
| `rooms` | Список аудиторий без HTML. |
| `type` | Тип занятия из ответа сайта. |
| `weekday` | День недели от 1 (понедельник) до 7 (воскресенье) или `None`. |
| `date_from`, `date_to` | Границы периода проведения занятия или `None`. |
| `date` | Конкретная дата занятия или `None` для неразвернутой недельной сетки. |
| `link` | Ссылка из поля `e_link` сайта или `None`. |

### `Deadline`

Содержит все поля `Lesson` и два дополнительных:

- `kind` - `"lab"` или `"practice"`;
- `days_left` - число дней от начала запрошенного периода до занятия.

### Преобразование в словарь

`lesson.model_dump()` возвращает словарь с объектами Python, включая `datetime.date`.

`lesson.model_dump(mode="json")` возвращает словарь, подготовленный для JSON: даты становятся строками вида `2026-11-16`. Сам метод не создает JSON-строку.

```python
lessons = await get_schedule("261-329")
data = [lesson.model_dump(mode="json") for lesson in lessons]
```

## Ошибки

- `ScheduleError` - сайт вернул некорректные данные, ошибку группы или не удалось пройти проверку `bpc`.
- `httpx.HTTPError` - ошибка HTTP-запроса, включая таймаут и неуспешный HTTP-статус.
- `ValueError` - пустой номер группы или конец запрошенного периода раньше начала.

HTTP-ответ и статус ошибки выбирает вызывающий API-обработчик.

## Запуск из отдельного Python-файла

Создай файл `test_parser.py` рядом с `manage.py`:

```python
import asyncio

from parser import get_schedule


async def main():
    lessons = await get_schedule("261-329")
    for lesson in lessons:
        print(lesson.model_dump(mode="json"))


if __name__ == "__main__":
    asyncio.run(main())
```

Запускай из папки с `manage.py`:

```bash
uv run python test_parser.py
```

`asyncio.run()` запускает асинхронную функцию из обычного Python-файла. В асинхронном обработчике API используй непосредственно `await`.

Относительные импорты в `parser/schedule.py` требуют запуска в контексте пакета. Для имеющегося в нем тестового `main()`:

```bash
uv run python -m parser.schedule
```

Предпочтительный способ проверки - отдельный файл, импортирующий функции из `parser`.
